# claude

A personal library of design templates and themes for Claude to reference and apply during design work (presentations, docs, UIs, etc.).

Each template lives under [`design-templates/`](design-templates/) as a git submodule, with a catalog entry describing what it is and how to use it. See [`design-templates/README.md`](design-templates/README.md) for the full list.

## Using a template

```bash
git clone --recurse-submodules <this-repo-url>
# or, if already cloned:
git submodule update --init --recursive
```
